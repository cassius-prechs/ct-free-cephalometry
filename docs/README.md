# Project Page

Source for the project page of *"Toward CT-Free 3D Cephalometric Landmark
Estimation Using MediaPipe Face Landmarker."*

Built from the [Nerfies project page template](https://github.com/nerfies/nerfies.github.io)
(CC BY-SA 4.0).

## Local preview

```
python3 -m http.server -d docs 8000
```

then open http://localhost:8000.

## Deploying to GitHub Pages

This folder is served as `docs/` on the `main` branch. In the
repository's Settings → Pages, set the source to "Deploy from a
branch" → `main` / `/docs`.
